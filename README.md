# Система автоматической проверки транзакций на мошенничество

## Краткое описание
Система предназначена для автоматического выявления мошеннических транзакций с использованием настраиваемых правил (фильтров). Администраторы создают и управляют правилами через специализированный упрощённый язык (DSL), обеспечивая гибкость и контроль над процессом проверки.

## Основные возможности

### Управление правилами (фильтрами)
- Создание правил на специализированном упрощённом языке (DSL)
- Предварительная проверка правил на ошибки
- Управление через веб-API
- Приоритетная сортировка активных правил

### Проверка транзакций
- Последовательное прохождение транзакций через активные правила
- Блокировка транзакции при срабатывании любого фильтра
- Консистентность результатов проверок
- Логирование всех операций и результатов

### Управление доступом
- Управление учётными записями сотрудников через веб-API
- Контроль доступа к функциональности системы

### Отказоустойчивость и надёжность
- Ошибки в отдельных правилах не выводят систему из строя
- Обеспечение сохранности данных
- Предсказуемость работы системы

### Аналитика и мониторинг
- Статистика по срабатываниям правил
- Выявление рискованных объектов
- Отслеживание эффективности фильтров

## Техническая реализация

### Стек технологий
- **База данных:** PostgreSQL (основное хранение данных)
- **Кэширование и очереди:** Redis
- **Контейнеризация:** Docker
- **Документация API:** OpenAPI

### Архитектурные особенности
- Микросервисная архитектура (в контейнерах)
- Отказоустойчивая конструкция
- Масштабируемость компонентов
- Консистентность данных

## Принцип работы

1. **Создание правил:** Администратор создаёт правила на DSL
2. **Проверка правил:** Система проверяет правила на корректность
3. **Обработка транзакций:**
   - Транзакция поступает в систему
   - Последовательно проходит через активные правила (по приоритету)
   - При срабатывании любого правила — транзакция блокируется
   - Результаты логируются
4. **Аналитика:** Сбор статистики для дальнейшего анализа

## Ключевые преимущества

1. **Гибкость:** Возможность создания сложных правил через DSL
2. **Надёжность:** Отказоустойчивость и сохранность данных
3. **Предсказуемость:** Консистентные результаты проверок
4. **Масштабируемость:** Современный технологический стек
5. **Удобство управления:** Веб-API и полная документация

## Безопасность
- Защита от ошибок в правилах
- Контроль доступа к административным функциям
- Логирование всех действий
- Сохранность финансовых данных
